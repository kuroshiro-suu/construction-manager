# 開発思想 — 使う人のためのソフト

このアプリは、現場で仕事をしてきた人間が、既存の業務ソフトに感じた小さな不満から生まれた。

入力欄を増やせば便利になるわけではない。選択肢を増やせば親切になるわけでもない。確認ダイアログ、必須項目、編集禁止のセル。作る側には整然として見えても、毎日使う側にはただの手間になることがある。

**人間がソフトの都合に合わせるのではなく、ソフトが人間の仕事に合わせる。**

だから、自由に書けるところは自由に書けるようにする。Excelに慣れた人なら、コピーして、貼り付けて、行を足して、行を消せるようにする。入力した情報は別の画面や帳票にも使い回し、同じことを何度も入力させない。

一方で、必要な制限は設ける。自動計算する金額を直接書き換えられないのは、計算の整合性を守るため。支払額が未確定の工事を計上できないのは、原価を曖昧にしないため。**制限には、一つひとつ説明できる理由がなければならない。**

入力ミスや表記揺れのすべてを先回りして防ごうとはしない。使う人が判断できることまで、ソフトが奪わない。例外に対応するために専用機能を増やすより、基本の仕組みに融通を持たせたい。

そして、このアプリにはもう一つ目的がある。見積を作るときから原価を意識し、仕事の収支を自分で考えるきっかけにしてほしい。説教するのではなく、数字が自然と目に入る仕組みにする。

**目指すのは、多機能なソフトではない。仕事の邪魔をしない、使うほど役に立つ道具である。**

---

### 開発時の判断基準

- その入力は、本当に今、必要か。
- その制限は、なぜ必要なのか説明できるか。
- その操作は、毎日繰り返しても苦痛ではないか。
- すでに入力した情報を、もう一度入力させていないか。
- 機能を増やさず、既存の仕組みで解決できないか。

迷ったら、画面の格好よさより、現場で使う人の手数を優先する。
