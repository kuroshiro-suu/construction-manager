# 2026-11-20 権限・ログイン仕様更新メモ

## 今回確定した事項

- メールアドレス＋パスワードによるログイン、新規事業者作成、招待URLからのユーザー参加。
- オーナー／F／V／P／特例ゲストの権限表。Fだけ業者・単位マスター編集可。
- Pは工事別金額を閲覧できるが会社全体の収支は閲覧不可。
- ゲストは本人登録・許可された未受注工事の工事情報・見積・入金支払を編集でき、受注後即遮断。
- 画面とボタンは共通。権限不足は通知し、サーバー側認可で情報保護。
- オーナーの「権限削除」は事業者所属解除であり、ユーザーアカウントや業務データを削除しない。

## 注意

以前の仕様の「ゲスト：全権限／閲覧のみ／見積協力」は廃止した呼称。最優先は基本仕様書v1.0第12章。
認証の安全対策・未決定の業務ルールは勝手に仕様確定しない。
