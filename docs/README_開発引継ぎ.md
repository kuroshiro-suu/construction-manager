# 工事進捗・粗利管理システム 更新版引き継ぎ（2026年11月20日）

## 正式な参照優先順位

1. `開発思想_使う人のためのソフト.md`（判断基準）
2. `基本仕様書_v1.0.md`（全体構造・共通ルール）
3. `見積エディタ仕様書_v0.2.md`（見積・原価・印刷ページ）
4. `入金・支払仕様書_v0.3.md`（カード・精算調整・ロック後例外）
5. `支出台帳仕様書_v0.4.md`（会社支出・全社帳票）

既存4ファイル `index.html` / `construction.html` / `style.css` / `app.js` は**旧版のUI参考**。仕様の優先順位は最新版文書が上。ローカル保存のみで本番利用不可。

## この更新で反映した決定

- トップの共通入口を「設定」一本に統合し、**「事業者情報設定」**を設置する名称を決定。
- 税率は新規工事のみ標準値を適用、既存は工事情報で個別変更。
- 受注後は見積提出側、計上後は原価・取引先をロック。
- 計上後も支払額訂正と入金・支払実績日入力を認める。支払額の専用修正履歴は追加しない。
- 0円工事・予算0円でも実際の支払は入力し、赤字を正しく表示。

## 2026年11月20日追加確定：認証・権限

- メールアドレス＋パスワードでログイン、新規事業者作成者をオーナーとする。メール招待URLからユーザー登録またはログインして所属。
- ロールは**オーナー、F（全業務編集・マスター可）、V（全閲覧）、P（工事だけ金額も含め閲覧）、特例ゲスト（許可済み未受注工事のみ編集）**。
- 設定の**事業者情報・税率・決算月・ユーザー管理はオーナー専用**。**業者・単位マスターはオーナーとF**が編集。
- UIは共通。権限不足時に簡潔に通知するが、禁止情報はサーバー側からも取得不可。
- オーナーの「権限削除」は所属アクセス剥奪。ユーザー本人と既存工事データを消さない。
- 旧仕様書に残る「見積協力ゲスト」等の表記があれば**基本仕様書v1.0第12章**を優先。

## 未決定事項は維持
